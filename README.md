# The Banana Straightener

[![make.fun](https://make.fun/badge/bounty/the-catalogue-photo-of-an-2-20261121-0341)](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341)

A catalogue photograph of an impossible gadget: the Banana Straightener.
A sleek white countertop machine takes a curved banana in on the left and
serves a perfectly straight banana out on the right. One spare banana lies
on the studio floor as the single accessory.

`main.py` (pure Python 3.13 standard library, no third-party packages)
draws the 1024x1024 studio product shot and writes it to
`/output/entry.png`. Running it twice produces byte-identical output.

## Run

```sh
python3 -P -s main.py
```
